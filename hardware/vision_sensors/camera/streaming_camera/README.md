# streaming_camera

## 개념

로봇·기계 등에 탑재되어 RTSP/ONVIF로 실시간 영상을 네트워크에 발행하는 산업용 카메라 기술
카테고리입니다. 완제품형(Bullet/Dome/Block), 분리형(Remote Head), 보드/박스카메라형 세
폼팩터의 조달·환경스펙 트레이드오프와, 보드/박스카메라 채택 시 필요한 IP67~IP68급 자작
하우징 설계 원칙을 다룹니다.
