# gps_rtk

## 개념

고정밀 위성 항법 시스템(GNSS) 및 RTK(Real-Time Kinematic) 센서, 이중 안테나 Heading(방위각) 수신기 및 멀티 밴드 GNSS 안테나 기술 카테고리입니다. 센티미터급 정밀 위치 측정, NMEA/SBF 프로토콜 및 ROS 2 `/navsat/fix` 데이터 연동을 다룹니다.
